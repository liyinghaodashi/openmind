# openmind [color:#72A58A]

## 设计思路 [color:#C6A35C]

### 简约
- 尽可能少的功能
- 额外功能放在设置里，按需开启

### 键盘优先
- 尽量通过键盘输入和操作，减少鼠标使用

## mind 模式 [color:#D4776A]

### 开启方式
- 文件后缀为 .mind.md

### 原文同步
- 节点修改同步到右侧原文，可以实时双向修改

### 节点 [color:#D5AA45]
- 渲染

  - 渲染逻辑
    - 主节点（一级节点）
      - # 表示主节点
      - 可以有多个，使用黑底白字
    - 二级节点
      - ## 表示二级节点
      - 跟随在主节点之后
    - 三级节点
      - ### 表示三级节点
      - 跟随在二级节点之后，目前不做特殊处理
    - 细分节点
      - - 表示细分节点
      - 跟随在三级节点之后，目前不做特殊处理
      - 后续节点继续使用缩进的 - 嵌套
    - 层级约束
      - 严格遵循 # → ## → ### → 嵌套 -
      - 不允许省略层级


  - 渲染颜色
    - 每一个节点后可以跟一个颜色
      - 格式
        - [color:HEX]
        - 案例
          - ## 产品设计 [color:#xxx]      [color:#3B82F6]
      - 颜色文本本身在节点上不显示
      - 复制功能也不复制颜色字符到剪切板
- 节点状态
  - 未选中模式
    - 不响应节点操作快捷键
  - 选中模式
    - 单击节点进入，黑色边框表示选中
    - 不能输入，不显示输入光标
    - 上下左右方向键切换节点
    - Tab 新建子节点
  - 编辑模式
    - 双击节点、再次单击已选中的节点，或选中后按 Enter 进入
    - 可以输入和修改文字，显示输入光标
    - 方向键移动文字光标，不切换节点
    - Tab 新建子节点
    - Enter 完成编辑，回到选中模式

### 开启方式
- 文件后缀为 .md

### 快捷键
- 标题
  - command + 1 / 2 / 3 / 4 / 5
- 有序列表
  - command + [
- 无序列表
  - command + ]
- 代码块
  - command + k


### 便签弹窗

- 仅在md模式中在屏幕右
