# Markdown 功能展示

直接编辑正文，即时查看排版效果。

## 文字样式

**粗体** · *斜体* · ~~删除线~~ · `行内代码` · [链接示例](https://example.com)

> 引用：用一小段文字突出重点。

## 列表与任务

- 无序列表
  - 嵌套条目

1. 有序列表
2. 第二个步骤

- [X]  已完成的任务
- [X]  点击复选框切换状态

## 表格


| 功能     | 操作               |
| -------- | ------------------ |
| 插入表格 | ⌘T                |
| 调整表格 | 修改行列数量       |
| 图片     | 粘贴截图或拖入图片 |

## 代码块

```javascript
const message = 'Hello, Markdown!';
console.log(message);
```

---

### 编辑体验

通过大纲跳转标题，打开「原文」编辑 Markdown，或切换「便签小窗」置顶记录。编辑内容自动保存。
